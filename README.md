# Handmade Jewellery Website

A fully functional multi-page e-commerce website built as a project during my IT studies at Ekurhuleni East TVET College. The site showcases handmade and creative jewellery pieces with a clean, user-friendly design.

## Pages

- **Home** — Landing page with a slideshow of jewellery images
- **About Us** — Information about the jewellery brand and its story
- **Products** — Jewellery listings with images and descriptions
- **Register** — User registration page with form validation
- **Contact** — Contact form for customer enquiries

## Features

- Interactive image slideshow on the home page
- Search button that reveals a search form when clicked
- User registration page with input validation
- Contact form for customer enquiries
- Consistent navigation menu across all pages
- Form validation using JavaScript
- Styled throughout using CSS

## Built With

- **HTML** — Page structure and content
- **CSS** — Styling and layout across all pages
- **JavaScript** — Search toggle functionality and form validation

## What I Learned

- How to build and link multiple web pages together
- How to use PHP to handle form submissions on the backend
- How to write JavaScript validation to check user input before submission
- How to create a responsive and consistent navigation experience
- How to structure an e-commerce style website from scratch

## How to Run

1. Clone or download this repository
2. Run it on a local server (e.g. XAMPP or WAMP) to support PHP
3. Open `index.html` in your browser to view the home page
